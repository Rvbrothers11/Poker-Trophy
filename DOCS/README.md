# Poker-Trophy
A 3D printed small Poker Trophy

My project is a 3D printed trophy for Poker players. It is fully 3D printed, 5 cm in height, and 3cm in lenght and depth. It is inspired based on this trophy:

<img width="800" height="800" alt="image" src="https://github.com/user-attachments/assets/95dae0b9-7191-4f65-b9c3-85a1e9bba17a" />



I created this project to honor my friend who is a highly invested poker player and has had significant outcomes. He has taught me to persist even after continously failing! This project is an ode to his amazing hobby!

How to use?
1. Start by 3D printing all the parts in the CAD model folder in the repo. 
2. Solder the components onto the PCB as in the following picture and the PCB files in the PCB folder:

<img width="713" height="784" alt="image" src="https://github.com/user-attachments/assets/5506a4b8-872e-4e48-aacd-f2681ab996dd" />

3. Place the PCB in the 3D printed bottom base in the slit as shown and as per the schematic and editor:

<img width="1127" height="549" alt="image" src="https://github.com/user-attachments/assets/01824bbd-98e5-4b59-b533-d9a70c74e0e6" />
<img width="376" height="425" alt="image" src="https://github.com/user-attachments/assets/6f8fbdf0-0e9e-4fe2-8699-6221199a4ab2" />
<img width="1229" height="723" alt="image" src="https://github.com/user-attachments/assets/3366b738-5753-4afb-964c-0ed05747f299" />

4. Add on the top base and screw on the display joint

<img width="1109" height="817" alt="image" src="https://github.com/user-attachments/assets/059a55da-a55a-496a-8115-0d6b0cdfba71" />
<img width="525" height="571" alt="image" src="https://github.com/user-attachments/assets/d57482cb-2627-4a76-ade1-933a0b84ae9b" />

5. Join on the top main design and screw it on:

<img width="633" height="721" alt="image" src="https://github.com/user-attachments/assets/b6752078-0456-4833-8ddd-11f03b165578" />

6. Connect the trophy to your device using a USB 2.0 Type-A to Mini-B cable and upload the code from the repo.
